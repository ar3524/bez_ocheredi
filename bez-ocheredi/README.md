# Проект "Без очереди"

Прототип системы предзаказа готовой еды для Финансового университета, разработанный в рамках хакатона.

## Описание проблемы
Короткие перемены и большие очереди в столовой. Студенты тратят время на выбор и оплату.

## Решение
Веб-приложение (PWA), встроенное в сайт вуза. Позволяет заранее выбрать блюда, оплатить онлайн или при получении, и забрать заказ по QR-коду. Без установки отдельного мобильного приложения.

## Технологический стек (MVP)
* **Backend:** Node.js, Express.js (REST API)
* **Frontend:** HTML5, CSS3, Vanilla JS (без тяжелых фреймворков)
* **Генерация QR:** Библиотека `qrcode`
* **Хранение данных:** In-memory (для демо). В production планируется PostgreSQL + Redis (для кэша и резервирования остатков).

## Как запустить локально
1. Установите Node.js.
2. Склонируйте репозиторий.
3. Выполните `npm install`.
4. Запустите сервер: `npm start`.
5. Откройте `http://localhost:3000` в браузере.
